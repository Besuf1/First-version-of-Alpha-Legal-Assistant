# Knowledge-base administration

Place lawyer-approved `.md`, `.txt`, or text-based `.pdf` files in this folder, then restart/redeploy the app.

For Markdown files, use optional front matter:

```markdown
---
title: Commercial Code Overview
source_url: https://official-source.example/document
reviewed_on: YYYY-MM-DD
---
# Business organizations

Approved text goes here.
```

## Publication checklist

Before adding legal material, confirm:

1. The document is authentic and permitted for this use.
2. Its proclamation/regulation/directive number and publication date are recorded.
3. Amendments, repeals, transitional rules, and implementation directives have been checked.
4. A qualified Alpha Advocates lawyer has approved the summary and marked a review date.
5. The document contains no client-confidential or personal data.
6. Scanned PDFs have searchable text or have been OCR-processed.

The prototype ships with firm-profile and service information from the firm's public website. It intentionally does **not** treat unverified legal summaries as current law.
